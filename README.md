# 🛡️ Email Threat Intelligence Platform

**SIH 2026 | PS 261016 | Team Dino Coders**

An AI-powered forensic intelligence platform that analyzes raw email files (.eml) to detect phishing, BEC, and impersonation threats using a multi-model ML pipeline. Features IP geolocation, SPF/DKIM/DMARC authentication verification, IOC correlation, and blockchain-backed chain-of-custody for digital evidence.

## ✨ Key Features
- 🔍 **Threat Detection** — RoBERTa/DistilBERT NLP for phishing, BEC & impersonation classification
- 📊 **Calibrated Risk Scoring** — Fused fraud-risk score (0–100) with SHAP explainability
- 🌍 **GeoLocation & Origin Analysis** — IP geolocation with ASN/VPN/TOR context mapping
- 🔐 **Email Authentication** — SPF, DKIM, DMARC validation with contextual analysis
- 🔗 **Blockchain Evidence** — Artifact hashing & tamper-proof chain-of-custody (Polygon/Ethereum)
- 📈 **Analyst Dashboard** — Interactive forensic reports with Leaflet maps & IOC graphs

## 🛠️ Tech Stack
`Python` `FastAPI` `PyTorch` `Transformers` `XGBoost` `SHAP` `NetworkX` `PostgreSQL` `Next.js` `Tailwind` `Leaflet` `Solidity`
